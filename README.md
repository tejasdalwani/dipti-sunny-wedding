# Dipti & Sunny — Wedding Invitation Website

A responsive React + Vite wedding invitation starter.

## Run locally
1. Install Node.js (LTS).
2. Extract this ZIP.
3. Open the project folder in VS Code.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local URL shown by Vite.

## Build
Run `npm run build`. The production website is generated in `dist/`.

## Replace placeholders with real media
Add these files to `public/assets/`:
- `wedding-video.mp4` — final Google Vids export
- `couple.jpg` — couple photo (to be wired into the design)
- `raavya.jpg` — Raavya's real photo
- `noddy.jpg` — Noddy's real photo
- `music.mp3` — optional instrumental background track

The current website intentionally uses tasteful placeholders until the real photos and final video are supplied.

## Before publishing
- Confirm the RSVP destination and connect a real form service. The current RSVP is a front-end preview and does not transmit responses.
- Confirm the venue's exact Google Maps pin/address.
- Add the final video and real family photos.
- Review every name and invitation line with the family.
- Add the final interactive PDF once the website is approved.
